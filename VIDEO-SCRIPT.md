status: draft, needs Cosmin's rewrite pass before publication

## Spoken script

I build and extend performance-sensitive software.
A lot of my day is figuring out what changed, which results still apply, and what needs checking again.

I built Impactor here this weekend to make that visible.

Changing the load or weather can make an old delivery result misleading. The agent needs to remember its conditions.

Here is a customer rollout, with engineering, GTM and accounts working toward one goal. I can go from three agents to a hundred, but shared builds and reviews still limit how quickly work finishes.

Save the completed checks, change the code, and watch which tasks need to run again. The cost estimate changes because we avoid repeated work and route handoffs to their owners.

GBrain stores those conditions. Memorable retrieves checking procedures in the delivery lab. Jev assesses whether a result still applies.

The same approach works for a customer configuration change, an updated offer, or a new software release.

## Screen sequence

- 0-11 seconds: Delivery lab, orbit the world slightly while introducing your background.
- 11-23 seconds: Show a changed condition, then the relationship graph.
- 23-37 seconds: Open Workplace. Select 3 agents, then 100. Point to the finishing-time curve and review slots.
- 37-49 seconds: Click Remember completed checks, then Code v1. Show the dimmed reused tasks and changed cost estimate.
- 49-60 seconds: Show the task conditions and the customer rollout goal. End on the workplace.

Aim for a conversational pace. The spoken text is about one minute at roughly 150 words per minute. The values on screen are simulation outputs and cost estimates.
